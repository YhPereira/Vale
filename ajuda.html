Central de Ajuda & Suporte

Guia passo a passo para navegação e utilização do Sistema de Localização de Ativos da Vale.

Para mais informações clique aqui: Documentação Completa no Google Docs

Como consultar a localização rápida de um item na página Inicial?
  1. Clique no botão Início no menu de navegação superior.
  2. Localize o campo com o texto "Digite o nome ou código do item (ex: PAT-2201)..." na seção central.
  3. Digite o código do patrimônio ou nome da ferramenta desejada.
  4. Verifique o resultado na tabela Resultados da Pesquisa informando a coluna Localização e o estado na coluna Estado.
Como fazer uma consulta avançada por categoria de ativo?
  1. Clique no botão Pesquisar no menu superior de navegação.
  2. Clique na caixa de busca "Digite o nome, setor ou código (ex: PAT-0300)...".
  3. Digite a categoria procurada (ex: Hidráulica, Filtros, Conexões ou Ferramentas).
  4. Confira a listagem exibida na tabela Todos os Itens Encontrados com as colunas Código PAT, Nome do Item, Categoria, Localização e Estado.
Como realizar a leitura de uma etiqueta de patrimônio por QR Code ou Câmera?
  1. No menu principal, clique na opção Leitura de Código.
  2. Aponte a câmera do seu dispositivo móvel ou coletor de dados para a etiqueta física colada na ferramenta.
  3. Aguarde a confirmação na caixa indicadora "[ Câmera / Leitor Óptico Ativo ]".
  4. O sistema identificará a etiqueta e exibirá os dados do ativo automaticamente na tela.
Como verificar quem retirou ou devolveu um equipamento?
  1. Acesse o menu superior e clique em Histórico.
  2. Consulte a tabela Últimas Transações.
  3. Confira o registro observando as colunas Data / Hora, Código PAT, Item, Colaborador e o tipo de Ação (ex: Retirada, Devolução ou Enviado p/ Manutenção).
Como encontrar os contatos da equipe de desenvolvimento do sistema?
  1. Clique na opção Sobre no menu de navegação.
  2. Navegue até os cartões dos integrantes da equipe (Yuri Honorato ou Filipe).
  3. Clique no botão Perfil no Instagram abaixo do integrante com quem deseja entrar em contato.
Como reportar instabilidade ou dúvidas não cobertas por este guia?
  1. Acesse o destaque superior com a mensagem "Para mais informações clique aqui".
  2. Abra o documento oficial no Google Docs para ler as diretrizes operacionais de TI.
  3. Se o problema persistir, entre em contato via ramal interno ou acione a equipe na página Sobre.
